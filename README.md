# TARS-Robotic-System

## Project Overview
TARS is a Raspberry Pi 5-based voice-controlled robotic assistant developed as a working prototype.

The project explores voice interaction, AI-based responses and basic hardware control using Python and Raspberry Pi.

## Key Features
- Wake-word activation using "HEY TARS"
- Voice recognition and speech processing
- AI-generated responses using a locally running language model
- Text-to-speech responses
- Ultrasonic sensor integration
- Motor control
- LED matrix expressions

## Technologies Used
- Python
- Raspberry Pi 5
- Linux
- Whisper
- Ollama
- Llama 3.2 (1B)
- pyttsx3
- sounddevice
- Ultrasonic sensor and DC motors
